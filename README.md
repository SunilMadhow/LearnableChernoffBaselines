# Learnable Chernoff Baselines

## Data & checkpoints

Trained models and sampled outputs (`.pt` files, ~9 GB) are too large for GitHub and are hosted on Google Drive:

https://drive.google.com/drive/u/0/folders/1X-lbH0B5hxp_Jx3U2IyRBY6vV0xqumPs

Download the run folders into `syntax_reward/data_runs/`, so the scripts find them at
`syntax_reward/data_runs/<run_id>/` (e.g. `20251224_233551_699407`, `20260205_195651_634076`).
`prompt_scaled/value_fn_normed.pt` belongs in `prompt_scaled/`.
